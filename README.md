# ACOREM
Andy's Comment Remover

## Usage
Go to the folder where the file you want to clean is, run 
```acorem 'your file'```
And it will create a new file called "temp", free from all comments.

## Install
Go to your repos folder and run this command
```git clone https://github.com/AndySundae/ACOREM.git && cd ACOREM && make && sudo make install```

## Update
Inside your repos folder
```cd ACOREM && git pull && make && sudo make install```

### Why i create this repo
I started studying C a month ago with the book "The C Programming Language" by Brian W. Kernighan & Dennis M. Ritchie, I was doing exercise 1-23 that is precisely a comment remover, so i thought, why not make this a scalable project for my github?
